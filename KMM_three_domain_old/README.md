# KMM: исходный эксперимент на трёх датасетах

Пакет для передачи коллеге, 2026-10-06. Все необходимые **подготовленные данные** включены; скачивать данные для запуска не нужно.

## Что открыть

- `experiments/kmm_three_domain_benchmark.py` — основной воспроизводимый эксперимент.
- `experiments/verify_kmm_three_domain.py` — численные проверки и проверка отсутствия использования target-меток при построении оценки/интервала.
- `results/kmm_three_domain/report.md` — отчёт с интерпретацией и ограничениями.
- `results/kmm_three_domain/mean_table.tex` — таблица оценки среднего отклика.
- `results/kmm_three_domain/risk_table.tex` — таблица оценки риска фиксированного предиктора.
- `results/kmm_three_domain/*_tasks.csv` — все результаты по отдельным задачам.
- `results/kmm_three_domain/*_protocol.json` — признаки, преобразования отклика и протоколы.
- `originals/kmm_three_domain_benchmark.py` — побайтовая копия первоначального скрипта. В рабочей копии изменены только два аспекта путей: удалён локальный путь к h5py и заменён абсолютный резервный путь NOAA. Вычисления не изменены.

Это **первоначальный** benchmark, НЕ последующий эксперимент «source=100 / большой target». Последний намеренно не смешан с этим пакетом.

## Данные

1. `data/pm25/beijing_pm25_daily_prepared.csv`: подготовленные станционные суточные наблюдения Beijing PM2.5. Source 2015, target 2016, поквартальные задачи; обучение предиктора на 2013–2014.
2. `data/noaa/ghcn2025_benchmark.csv`: подготовленные станционные суточные NOAA GHCN TMAX/TMIN/PRCP за 2025; разные станции source/target, отдельные станции для обучения предиктора. Это не сырые архивы GHCN.
3. `data/tnbc/tnbc.h5ad`: публичный обработанный TNBC MIBI-TOF; все данные включены. `data/tnbc/provenance.json` содержит источник и условия CC BY 4.0: Qian (2024), https://doi.org/10.6084/m9.figshare.26068006.v2, обработанные данные Keren et al. (Cell, 2018). При использовании сохраняйте атрибуцию. Файл фактически HDF5, несмотря на суффикс .gz в названии у источника.

TNBC-отклик — положительная часть уже стандартизованного Ki67, обрезанная и нормированная по обучающим пациентам; это **не сырая концентрация**. Ki67 исключён из признаков. Для всех доменов отклик ограничен [0,1].

Исходные сырые архивы и полный upstream-пайплайн подготовки в пакет не включены: воспроизведение начинается с приложенных prepared-файлов. Они достаточны для воспроизведения всех вычислений основного скрипта. Лицензия на экспериментальный код здесь отдельно не назначается; условия исходных данных сохраняются.

## Запуск

Откройте терминал в этой папке. Нужны Python и пакеты из `requirements.txt`. Рекомендуется отдельное виртуальное окружение; первоначальные результаты получены на Python 3.8.

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python experiments/verify_kmm_three_domain.py
python experiments/kmm_three_domain_benchmark.py --summarize-only
```

Последняя команда пересобирает отчёт/таблицы из сохранённых результатов, без нового обучения.

Для полного пересчёта сначала **переместите** приложенную папку `results/kmm_three_domain` в резервную папку, например `results/kmm_three_domain_saved`, затем:

```sh
python experiments/kmm_three_domain_benchmark.py --dataset all
python experiments/verify_kmm_three_domain.py
```

Можно запускать отдельно `--dataset PM25`, `--dataset NOAA`, `--dataset TNBC`. Скрипт продолжает расчёт из существующих CSV: если их оставить на месте, уже завершённые задачи пропускаются. Численные результаты могут немного различаться между версиями библиотек; точные исходные версии указаны в `environment_original.txt`.

## Научные ограничения

Сравниваются Unweighted, Logistic IW, KMM iid и KMM + dependence. Среднее и риск — разные estimands; риск — квадрат ошибки отдельно обученного и затем фиксированного Random Forest, не регрессионная GP-модель.

Target-метки используются только при оценке результата. Интервалы — source-only plug-in, условные на оценённых весах и target-ковариатах. Не учитывается полностью неопределённость подбора весов или target population. Задачи разделяют станции/пациентов, поэтому не являются независимыми повторами.

**Важно:** именно в первоначальном скрипте dependence variance ограничена снизу iid variance: `max(viid, vdep)`. Поэтому corrected interval по конструкции не уже iid. Temporal: Bartlett HAC 14 дней; spatial: Gaussian taper по координатам, не Gaussian Process regression. Это эмпирический stress test, не проверка теоремы и не гарантия номинального покрытия.

## Целостность

`MANIFEST_SHA256.csv` содержит размер и SHA256 каждого включённого файла (кроме самого манифеста). Сам архив не включает виртуальное окружение, личные файлы и локальные бинарные библиотеки.
